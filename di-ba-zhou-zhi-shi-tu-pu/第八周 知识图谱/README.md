# 神经网络概述 · 3D 知识图谱

《人工智能导论》第 8 周（4.2 神经网络概述）的三维知识图谱。数据全部来自课件
`4.2 神经网络概述.pptx`（56 页），**171 个知识点、185 条关系线**，用 three.js 渲染。

打开 `神经网络概述-3D知识图谱.html` 即可。**单文件、零外链脚本、断网可用** ——
three.js 全部内联在里面，拷进 U 盘、双击、投屏。

## 一、这张图的骨架：智能浪潮

第 2 讲的骨架是「制度浪潮」，这一讲的骨架是**「国家战略 · 人工智能+」**——
一条三维浪潮带从 2017 流向 2026：新一代 AI 规划立纲、2023 治理起步、
2024「人工智能+」首次提出、2025 国务院深入实施、四中全会全面实施、
2026 智能经济，浪潮随之陡升。

- **政策节点按年份落带**：2017 规划、2023 管理办法、2024 首提「人工智能+」、
  2025 国发 11 号、2025.10 十五五建议、2026 智能经济——每枚都由牵引线钉回曲线上。
- **金环给里程碑**：2017 规划 · 2024 首提 · 2025.10 全面实施。
- **八个分支像一道长卷**：课程导入、前馈、卷积在左，循环、对抗、Transformer
  居中，应用、产业与国家战略在右；母题「神经网络」悬在最顶上。
- **虚线是这张图存在的理由**：刷脸支付接上 CNN、隐藏状态接上位置编码、
  1986 BP 接上 1998 LeNet-5、BERT 接上 LLM 黄金时代。按 <kbd>K</kbd> 打开。

配色与第 2 讲同一套星图语言：深空墨蓝底，八个分支从琥珀、蓝、青、紫红、
橙到紫、绿、中国红（菲涅耳亮边节点 + 辉光），母题青白，金环专给里程碑。
宋体做标题，等宽做年份。

## 二、课堂怎么用

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 / 右键 | 旋转 / 缩放 / 平移 |
| 悬停 | 点亮一条支路，其余退到背景 |
| 点击节点 | 相机飞过去，右侧展开讲解、关键词、相邻知识点、**课件页码** |
| <kbd>空格</kbd> | **18 站自动导览**，可直接当小结用（含智能浪潮思政站） |
| <kbd>K</kbd> | 跨章节关联虚线 |
| <kbd>S</kbd> | 导出当前视角 PNG（右下角自动加标题，可直接贴进 PPT） |
| <kbd>R</kbd> / <kbd>H</kbd> / <kbd>Esc</kbd> | 复位 / 隐藏界面 / 收起面板 |
| 搜索框 | 搜概念、年份、网络名称，命中处整体点亮并自动取景 |

左侧「读图」面板解释了每一种视觉编码，学生自己看也知道怎么读。

## 三、与第 2 讲项目的关系

本项目由 `第二周 知识图谱`（认识大数据）改制而来，复用其全部机械（布局求解、
标签 LOD、取景求解、导览、导出、移动端形态），改动四处：

1. **`src/data.js` 全部重写**：171 节点对应第 8 周课件，页码为 56 页版编号；
   八个分支（导入回顾 / 前馈 / 卷积 / 循环 / 对抗 / Transformer / 应用 / 产业与战略）。
2. **浪潮带语义**：从「数据要素制度的加速度」改为「人工智能+国家战略的加速度」，
   波形剖面（WAVE_PROFILE）与年份轴（2017→2026）同步改写；带 band 标记的节点
   依旧按年份钉上曲线。
3. **布局适配八分支**：章级坐标改写为近排 / 远排深浅交替；扇形布局（fanOut）
   纵向改线性等距、深度抖动改单调渐变、六七节的分支扇面自适应加宽——
   分支数量翻倍后标签依然打得开。
4. **取景偏置**：横屏注视点左偏让出读图栏，竖屏给右缘的母题标签留边。

## 四、目录与怎么改

```
神经网络概述-3D知识图谱.html  ← 交付物：双击打开
src/
  data.js      知识图谱数据（171 节点 / 树 / 15 条跨章节关联 / 18 站导览），逐条标注课件页码
  app.js       三维场景、布局求解、交互、导览、导出
  style.css    HUD 样式（星图 × 测量仪器的设计语言）
  index.html   外壳模板
vendor/        three.js r147 UMD + 官方后处理（MIT），构建时内联
build.mjs      把上面全部合成单文件：node build.mjs
datacheck.mjs  数据完整性校验：node datacheck.mjs
dump.mjs       无头导出真实节点坐标：node dump.mjs [宽] [高] → _scene.json
layout.mjs     几何验收（出画 / 标签 LOD / 重叠 / ASCII 鸟瞰）：node layout.mjs
shots.mjs      多机位截图：node shots.mjs [宽] [高] [机位 …]
```

改内容只动 `src/data.js`；浪潮簇的节点加 `band: true` 和 `wave:{year, lift}`。
改完跑 `node datacheck.mjs` 与 `node build.mjs`。
