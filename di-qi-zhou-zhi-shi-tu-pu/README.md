# 神经网络简介 · 3D 知识图谱

《人工智能导论》第 7 讲（4.1《神经网络简介》）的三维知识图谱。数据全部来自课件
`4.1 神经网络简介.pptx`（67 页），**105 个知识点、120 条关系线**，用 three.js 渲染。

打开 `神经网络简介-3D知识图谱.html` 即可。**单文件、零外链脚本、断网可用** ——
three.js 全部内联在里面，拷进 U 盘、双击、投屏。

## 一、这张图的骨架：四次起落

第 2 讲的骨架是「制度浪潮」，这一讲的骨架是**「发展历史 · 四次起落」**——
一条三维浪潮带从 1943 流向 2026，就是这门学科八十年的温度计：

- **历史节点按年份落带**：1943 M-P 模型、1949 Hebb 规则、1958 感知器、
  1960 Adaline、1969《Perceptrons》、1982 Hopfield、1985 HNN 解 TSP、
  1984 玻尔兹曼机、1986 BP、1989 LeNet、2006 深度学习、2007 ImageNet、
  2012 AlexNet、2016 AlphaGo——每枚都由牵引线钉回曲线上，
  曲线在 1969–1976 沉入谷底（低潮时期）、2012 后陡升（高潮时期）。
- **浪潮尾段汇入国家战略**：2017 新一代规划、2018 高校行动计划、
  2023 治理起步、2024「人工智能＋」、2025 实施意见、2026 智能经济——
  课程思政的六个节点接在同一条曲线的尾段上，技术史与思政在线上接棒。
- **金环给里程碑**：1943 M-P · 1958 感知器 · 1969《Perceptrons》·
  1982 Hopfield · 1986 BP · 2006 深度学习 · 2012 AlexNet · 2016 AlphaGo · 2017 新一代规划。
- **五个部分像一道浅拱**：课程导入、深度学习概述在左，课程思政在右；
  神经网络概述（本讲主场，29 个节点）居中偏右在前；发展历史骑在浪潮上方；
  母题「神经网络简介」悬在最顶上。
- **虚线是这张图存在的理由**：树突对应输入、连接强度对应权值、
  单层之坎对应《Perceptrons》、AlphaGo 对应国家战略。按 <kbd>K</kbd> 打开。

配色与第 2 讲同一套星图语言：深空墨蓝底，五个部分从琥珀、蓝、青、橙到紫藤
（菲涅耳亮边节点 + 辉光），母题青白，金环专给里程碑。宋体做标题，等宽做年份。

## 二、课堂怎么用

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 / 右键 | 旋转 / 缩放 / 平移 |
| 悬停 | 点亮一条支路，其余退到背景 |
| 点击节点 | 相机飞过去，右侧展开讲解、关键词、相邻知识点、**课件页码** |
| <kbd>空格</kbd> | **16 站自动导览**，可直接当小结用（含思政站与跨章节关联站） |
| <kbd>K</kbd> | 跨章节关联虚线（16 条） |
| <kbd>S</kbd> | 导出当前视角 PNG（右下角自动加标题，可直接贴进 PPT） |
| <kbd>R</kbd> / <kbd>H</kbd> / <kbd>Esc</kbd> | 复位 / 隐藏界面 / 收起面板 |
| 搜索框 | 搜概念、年份、模型（试试「感知器」「激活函数」），命中处整体点亮并自动取景 |

左侧「读图」面板解释了每一种视觉编码，学生自己看也知道怎么读。

## 三、与第 2 讲项目的关系

本项目由 `第二周 知识图谱`（认识大数据）改制而来，复用其全部机械
（布局求解、标签 LOD、取景求解、导览、导出、移动端形态），改动四处：

1. **`src/data.js` 全部重写**：105 节点对应 4.1 课件 67 页，逐条标注课件页码。
   树：00 课程导入（13）· 01 深度学习概述（18）· 02 神经网络概述（29）·
   03 发展历史（23）· 04 课程思政（21）+ 母题。
2. **浪潮带语义**：从「数据要素制度的加速度」改为「学科温度计 · 四次起落」——
   `WAVE_PROFILE` 改为 1940→2026 的起落曲线，年份映射改为线性
   （三段密集期 1958–63 / 1982–89 / 2006–26 平分呼吸空间）。
   布局代码仍用 `band` 标记识别浪潮簇；并打了一行补丁：
   **fanOut / sprayLeaves 跳过 band 子节点**（原版浪潮节点的坐标会被扇形布局覆盖）。
3. **视觉与第 2 讲同款（深空星图）**：菲涅耳节点着色器、UnrealBloomPass、
   加色混合连线、橙色浪潮带全部保留，两个图谱可直接混用。
4. **`layout.mjs` 的浪潮校验**改为四次起落语义（低潮是谷底、高潮是最高点）。

## 四、目录与怎么改

```
神经网络简介-3D知识图谱.html  ← 交付物：双击打开
src/
  data.js      知识图谱数据（105 节点 / 树 / 16 条跨章节关联 / 16 站导览），逐条标注课件页码
  app.js       三维场景、布局求解、交互、导览、导出
  style.css    HUD 样式（星图 × 测量仪器的设计语言）
  index.html   外壳模板
vendor/        three.js r147 UMD + 官方后处理（MIT），构建时内联
build.mjs      把上面全部合成单文件：node build.mjs
datacheck.mjs  数据完整性校验：node datacheck.mjs
dump.mjs       无头导出真实场景几何：node dump.mjs [宽] [高] → _scene.json
layout.mjs     纯几何构图验收：node layout.mjs（出画 / 标签重叠 / 浪潮形状）
shots.mjs      多机位截图取证：node shots.mjs → shots/*.png
```

改内容只动 `src/data.js`；浪潮簇的节点加 `band: true` 和 `wave:{year, lift}`
（stage 小结等仅用于取位的节点，详情面板不会显示年份标签）。
改完依次跑 `node datacheck.mjs` → `node build.mjs` → `node dump.mjs 1600 900`
→ `node layout.mjs`，需要截图时 `node shots.mjs`。
